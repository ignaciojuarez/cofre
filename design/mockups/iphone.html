One app, then play.

Air's launcher, JIT and a local VPN in one development-signed app. Set it up once, then it just plays.

Distribution: TestFlight strips get-task-allow, which means no JIT. Cobble ships as a development-signed build installed from a link: registered UDIDs only, and each build expires after 1 year.

01Setup

Set up once

Six checks, about five minutes. Each screen checks itself and moves on when it passes.

02Play

Tap Play

Home shows one instance and one button. Instances cover Vanilla, Fabric, Quilt, Forge and NeoForge, each in its own folder.

03Mods

Find, install, toggle

Modrinth and CurseForge in one search. Only mods that fit the instance are shown, and dependencies install with them. Import .mrpack and .zip packs, toggle any mod.

04Settings

Every Air setting, sorted

Game, Controls and System hold everything Air already has: RAM, renderers, MobileGlues, FSR, touch and controller, gyro, Java, mirrors, keys, logs and looks.

05System

Blocks, not cards

Styled after playhorizon.dev: square blocks with a 2 px outline, a bevel on top and a 4 px lip below. Pixelify Sans for anything you tap, Geist for reading, Geist Mono for labels. All art here is drawn in code.
