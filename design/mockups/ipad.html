The regular-width versions of the iPhone tabs. Panes are the iPhone screens. Only the container changes.

Setup, launch, controls

Full-screen flows hide the shell. Setup is a centered card. Launch is an AdaptiveSplit of the scene and the progress/log. The controls editor stays Air's UIKit view controller, themed through the same tokens.

Pointer, keyboard, controller, windows

Hover adds a lighter overlay on any block. Keyboard focus draws a 2 pt accent ring outside the outline. Every action has a menu-bar command. A controller drives the same focus.

Component states

Every interactive block uses these five states, in dark and light. Active means pressed for buttons and rows, on for switches and chips, and editing for fields.
