# Installed mod rows
- Search and Installed use one `ModRow` built from the existing `Row` component.
- A project icon loads through the shared remote image pipeline.
- A jar icon is decoded lazily from cached metadata; the ore block is the fallback.
- Installed subtitles show a clean version and loader, or `Off`.
- Badges stay below the subtitle for compatibility, updates, and in-use packs.
- The trailing Installed switch owns its 44-point hit area.
- Row taps open the identified project page and leave the switch independent.
- Unknown jars open a compact local details sheet.
- Needs actions remain below the row; swipe/context Delete offers exclusive dependencies with checked boxes.
