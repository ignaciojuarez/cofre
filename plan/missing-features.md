# Cofre missing launcher features

- **Current shell:** Play, Instances, Mods, Settings, setup/JIT, launch progress, touch/controller controls, logs/crash, worlds and saved-server panes, and signed server-join UI.
- **Production status:** `MockBackend` is preview/test data (`app/UI/Sources/CofreUI/Mocks/MockBackend.swift:5`); `CofreBackendAdapter` is the real bridge. The adapter currently advertises only delete-world, add-server, env/renderer tuning, server-join and instance-icon capabilities (`app/Glue/AirBridge/CofreBackendAdapter.swift:26-29`).
- **Already wired:** Air-backed instance/world/server lists, Microsoft sign-in, JIT/VPN, typed Air preferences (`app/Glue/AirBridge/CofrePreferences.swift:8-39`), Modrinth/CurseForge search/dependency planning/install (`app/Glue/AirBridge/CofreBackendAdapter+Mods.swift:100-229`), log export (`app/Glue/AirBridge/CofreBackendAdapter.swift:293-294`).
- **Partly wired or missing:** world backup throws (`app/Glue/AirBridge/CofreBackendAdapter.swift:169-171`), pack import is an unavailable stream (`:295-297`), account removal throws (`:215`), device info is nil (`:328`), and the adapter omits most Minecraft `options.txt` settings.
- **Priority rule:** P0 blocks a credible first public release; P1 follows quickly; P2 is useful polish/ecosystem work; P3 is deliberately deferred.
